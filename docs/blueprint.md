# **App Name**: TomeAgua

## Core Features:

- Water Intake Entry: Input field for the user to enter the amount of water consumed in milliliters.
- Data Storage: Locally store the water intake data with timestamps using local storage.
- Intake History: Display a history of daily water intake, showing the amount and time of each entry.
- Daily Summary: Display a summary of total water intake for the current day.

## Style Guidelines:

- Primary color: Light blue (#B0E2FF) to represent water.
- Secondary color: White or light gray for the background to ensure readability.
- Accent: Teal (#008080) for interactive elements like buttons.
- Clean and modern fonts for easy readability on all devices.
- Simple, water-related icons for visual cues (e.g., a water drop for the intake entry button).
- Clean and intuitive layout with a clear separation between the input area and the intake history.
